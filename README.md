# 🧮 Python Calculator

A simple calculator made using **Python** that can perform basic arithmetic operations such as addition, subtraction, multiplication, and division.

## 📌 Features

* Addition (`+`)
* Subtraction (`-`)
* Multiplication (`*`)
* Division (`/`)
* Modulus (`%`)
* Simple and easy-to-use interface
* Handles basic division-by-zero errors

## 🛠️ Technologies Used

* **Python 3**

## 📂 Project Structure

```text
Python-Calculator/
│
├── calculator.py

```

## ▶️ How to Run

### 1. Install Python

Make sure Python 3 is installed on your computer.

You can check by running:

```bash
python --version
```

### 2. Clone or Download the Project

Download this project to your computer.

### 3. Run the Calculator

Open the project folder in a terminal and run:

```bash
python calculator.py
```
